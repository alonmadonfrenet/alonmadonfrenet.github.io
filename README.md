# Site CV de Frenet Alonmadon

Site statique (HTML, CSS, JS), sans dépendance externe.

## Publier sur GitHub Pages
1. Crée un dépôt public nommé `frenet-alonmadon.github.io` (remplace `frenet-alonmadon` par ton nom d'utilisateur GitHub).
2. Envoie-y tous les fichiers de ce dossier (`index.html` à la racine).
3. Dans Settings > Pages : Source = « Deploy from a branch », branche `main`, dossier `/ (root)`.
4. Ton site sera en ligne sur `https://TON-UTILISATEUR.github.io` après une à deux minutes.

## Mettre à jour
- Modifie `index.html` (textes) ; remplace `assets/CV-Frenet-Alonmadon.pdf` pour changer le CV téléchargeable.
- Domaine personnalisé : Settings > Pages > Custom domain.
